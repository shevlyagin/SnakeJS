# SnakeJS

A responsive browser version of the classic Snake game, built with HTML Canvas and vanilla JavaScript.

## Features

- Keyboard controls with arrow keys or WASD
- Collision detection for walls and the snake's body
- Score tracking and snake growth
- Food generation that avoids occupied cells
- Start, game-over, and restart states
- Responsive layout for desktop and mobile screens

## Technologies

- HTML5 Canvas
- CSS3
- Vanilla JavaScript

## Run locally

No installation or build step is required.

1. Clone or download the repository.
2. Open `index.html` in a modern browser.
3. Use the arrow keys or WASD to play.
